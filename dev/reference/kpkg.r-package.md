# kpkg.r: Create R Packages with Personal Conventions

A personal companion to 'usethis': create R packages with a predefined
author, license, tests and documentation setup, and add versioned
continuous integration templates for 'GitHub Actions' and 'GitLab CI'
(package check and 'pkgdown' site with a released and a development
version).
